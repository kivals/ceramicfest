# Программа фестиваля 2026 + афиша слева

## Контекст

Поступила программа сезона 2026 (изображение `tmp/afisha.jpg` + текст расписания). Сейчас в `src/content/seasons/2026.json` блок `program` находится в режиме `placeholder`. Нужно перевести в `announced`, добавить три дня (11–13 июня), а слева от событий первого дня (день открытия) показать афишу — как было в архиве 2023 для дня 16 июня.

## Цель

- Программа отображается на главной 2026 в виде трёх блоков-дней с событиями.
- К первому дню (11 июня) слева от списка событий прикреплена афиша.
- Файл афиши лежит в репозитории как WebP в каноничной папке ассетов; временная папка `tmp/` удалена.

## Объём изменений

1. Конвертация и размещение изображения афиши.
2. Расширение Zod-схемы `program.days[]` опциональным полем `images`.
3. Поддержка `images` в компоненте `src/components/sections/shared/Program.astro`.
4. Перевод `program` в `2026.json` в статус `announced` с заполнением `days`.
5. Удаление временной папки `tmp/`.

### 2. Схема контента

Файл: `src/content.config.ts`.

В Zod-схеме `seasons.program.days[]` добавить опциональное поле:

```ts
images: z.array(z.object({
  src: image(),
  alt: z.string(),
  ratio: z.enum(['pb100', 'pb140', 'pb177']).optional(),
})).optional(),
```

`ratio` — модификатор CSS-класса `.billboard__image-item._ibg.pbNNN`. Используется в существующих стилях из legacy 2023 для задания пропорций картинки-плейсхолдера. По умолчанию `pb140` (вертикальный плакат).

### 3. Компонент Program.astro

Файл: `src/components/sections/shared/Program.astro`.

Внутри ветки `status === 'announced'`, перед `<div class="billboard__program">`, добавить условный блок:

```astro
{day.images && day.images.length > 0 && (
  <div class="billboard__images">
    {day.images.map(img => (
      <div class={`billboard__image-item _ibg ${img.ratio ?? 'pb140'}`}>
        <div class="billboard__overlay"></div>
        <button class="billboard__button _icon-search"></button>
        <Image src={img.src} alt={img.alt} />
      </div>
    ))}
  </div>
)}
```

Импортировать `Image` из `astro:assets`. Разметка повторяет ту, что использовалась в архиве 2023 (`billboard__images` → `billboard__image-item` с overlay и кнопкой), чтобы заработали существующие SCSS-стили (двухколоночная раскладка через `.billboard__content`) и popup-модалка из `src/scripts/client.ts`.

Не трогаем ветку `placeholder` и `billboard__header` — они уже корректные.

### 4. Данные программы

Файл: `src/content/seasons/2026.json`, ключ `program`.

- `status`: `"announced"`.
- `placeholderText`: удалить.
- `title`: оставить `"Программа фестиваля"`.
- `days`: массив из трёх элементов.

Внутри дня:
- `date` — строка вида `"Четверг, 11 июня"`.
- `location` НЕ задаём на уровне дня (на 12 и 13 июня внутри дня две разные локации; для 11 июня тоже неявная). Подзаголовки секций («Мастер-классы (территория ИКЦ)», «Лекции-презентации (коворкинг ИКЦ)») идут как обычные пункты `events[].html`, обёрнутые в `<strong>`.
- `events[].html` — допустимы инлайн-теги (`<strong>`, `<br>`). Уже поддерживается через `set:html` в текущем компоненте.

## Условные обозначения форматирования

- Тире между временем и описанием события — длинное `—` (как на афише).
- Города — в круглых скобках с префиксом `г.`: `(г. Москва)`, `(г. Санкт-Петербург)`, как в источнике.
- Подзаголовки секций (Мастер-классы / Лекции-презентации) — обёрнуты в `<strong>`.

## Что НЕ входит

- Не меняется ветка `status: 'placeholder'` в компоненте.

- Не трогаются стили: используется существующий SCSS из `legacy` (двухколоночная раскладка billboard).
