# CeramicFest

Статический промо-сайт ежегодного фестиваля керамики. Обновляется каждый год: новая ветка git (`2021`, `2022`, ..., `2025`) и новые данные/фото для каждого сезона.

## Структура проекта

- `#src/` — исходники
  - `*.html`, `_*.html` — страницы и переиспользуемые фрагменты (header, footer, popup и т.д.)
  - `scss/` — стили (точка входа: `style.scss`)
  - `js/app.js`, `js/vendors.js` — скрипты
  - `data/members.json` — данные об участниках фестиваля
  - `img/` — изображения
  - `2021/`, `2022/`, `2022_2/`, `2023/`, `2024/` — архивные версии по годам
- `ceramicfest/` — собранный сайт (output, не редактировать вручную)

## Сборка (Gulp)

```bash
# Первый запуск
npm i
npm install webp-converter@2.2.3 --save-dev

# Разработка (watch + BrowserSync)
gulp

# Сборка
gulp build
```

Gulp-пайплайн: SCSS → автопрефиксер → минификация CSS, JS uglify, `@@include` для HTML-шаблонов, конвертация изображений в WebP, копирование шрифтов и JSON.

## Данные

Участники хранятся в `#src/data/members.json`. Структура записи:
```json
{
  "id": 4,
  "name": "Имя Фамилия",
  "position": "",
  "photo": "./img/members/Фамилия.webp",
  "altText": "Имя Фамилия",
  "description": "Биография...",
  "additionalDescription": "Дополнительно..."
}
```

## Работа с фото

**Все новые фото и картинки перед добавлением в проект обязательно прогонять через `img-convert.js`.** Оригиналы после конвертации удалять.

```bash
# Конвертировать папку (файлы сохраняются рядом с оригиналами)
node img-convert.js ./путь/к/папке

# Конвертировать в отдельную папку
node img-convert.js ./источник -o ./output

# С ограничением ширины
node img-convert.js ./источник --width 1920
```

Скрипт конвертирует JPG, PNG, GIF, TIFF → WebP с качеством 82 по умолчанию. Папка `photos/` используется как staging для новых фотографий.

## Ветки
